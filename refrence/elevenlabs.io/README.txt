HOW TO VIEW (recommended - animations, fonts and JS work properly):
  Windows : double-click start-server.bat      (needs Python installed)
  Mac/Linux: run  sh start-server.sh
  Then open http://localhost:8000/

No Python? Use VS Code "Live Server" extension, or run:  npx serve .

Opening index.html directly (file://) works for simple sites, but some
scripts, fonts and animations need a local server.

Notes:
- Files from other domains (CDNs) are stored under _external/
- Files that were too big or failed to download still load from the original URL.
- Contact forms, logins and APIs will not work offline.
